# Aidroom public archive assets

The archive reader and its public research tools use the versioned catalog in this repository. It contains the published record text, citation details, search index, page images, and browser assets for the Aidroom edition of the USAID Files. The source agency is identified on each record. The attached MP4s are the reviewed playback copies used by the reader.
